# Phase 14 — Agency Mode

**Status:** Not started · **Depends on:** Phase 13 (agency plans) · **Milestone:** M7

## Prerequisite decisions
Agency model (recommended: agency is its own organization with explicit, audited, revocable grants to client organizations); agency pricing.

## Milestones
1. Agency ↔ client grant model (designed in Phase 1) implemented with RLS-compatible access paths
2. Client invites/acceptance; delegated roles; revocation
3. Cross-client overview without cross-client data mixing
4. Audit of every delegated action

## Exit criteria
Isolation tests across agency/client and between clients pass.
